6.5단계 — 인사와 짧은 반응

씬: Assets/Mid/Mid_Landscape.unity
Mid_PushCycle 오브젝트의 MidFriendGreeting 컴포넌트가 기존 MidPushCycle.phase를 읽는다.
기존 돌의 메시 생성, 원본 정점, 행렬 계산, 밀기/후퇴 시간은 수정하지 않는다.

시간 (기존 12초 주기 기준)
- 8.00~8.55초: 하치와레가 머리를 치이카와 쪽으로 조금 더 돌린다.
- 8.25~8.85초: 왼팔을 들어 올린다.
- 8.85~10.25초: 작은 인사를 두 번 한다.
- 10.25~10.95초: 왼팔을 내린다. 머리는 11.15초까지 원래 방향으로 돌아온다.
- 8.65~9.25초: 치이카와가 정자 방향으로 고개를 돌린다.
- 10.30~11.10초: 치이카와가 고개를 원래 방향으로 돌려 다음 시도를 준비한다.

기존 팔 중심 Pivot과 계층은 유지한다. 팔 메시의 어깨 접점 (0, 0.09, 0)을 기준으로 회전한 뒤 중심 위치를 역산하므로 팔이 몸에서 떨어지지 않는다.
회전은 매번 초기 자세로부터 계산한다. 치이카와 반응은 MidPushCycle.Update가 계산한 이번 프레임 머리 자세에 LateUpdate에서 추가한다.
하치와레 Root 및 다리 위치, 캐릭터 Prefab과 공유 메시/재질은 변경하지 않는다.

설정 메뉴: Mid > Animation > 2. Set Up Friend Greeting
구도 메뉴: Mid > Views > 1. Overall / 2. Waiting Place
새 오브젝트나 Animator Controller를 만들지 않고 기존 Mid_PushCycle에 컴포넌트 하나를 붙인다.

바위 크기 보정: 원본 메시를 보존하고 정점 좌표가 0.75배인 별도 메시와 RestData를 사용한다. 굴림 유효 반지름은 0.55에서 0.4125로 변경했다. 기존 행렬 변환 코드와 반복 경로는 유지한다.
설정 메뉴: Mid > Environment > Use 75 Percent Rock (원본 기준으로 적용하므로 반복 실행해도 추가 축소되지 않음).

인사하는 팔은 캐릭터 본인 기준 왼팔이다. 기존 부위명은 정면 화면 기준이므로 Hierarchy에서는 Hachiware/RightArm에 해당한다. Prefab 부위명은 유지하며 회전 방향만 좌우 대칭으로 맞춘다.
