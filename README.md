# 컴퓨터그래픽스 과제

## S02 - 기본 도형으로 탁자 만들기

- 과제 씬: [S02_HW](Assets/S02/S02_HW.unity)
- 큐브 1개와 원기둥 4개의 Transform을 조정하여 탁자를 구성한다.
- Scene 뷰의 이동·회전·크기 조절 도구와 시점 탐색 기능을 실습한다.

## S03 - 커스텀 다각형 메시 만들기

- 정점 5개 이상의 커스텀 다각형을 구현하고 Scene 뷰와 Game 뷰에서 확인한다.
- 과제 씬: [S03_HW](Assets/S03/S03_HW.unity)
- 정점 5개와 삼각형 3개로 집 모양의 평면 오각형을 구성한다.
- 분홍색 재질을 적용하고, 정면 카메라로 다각형의 형태를 확인한다.

## S04 - 커스텀 다이아몬드 메시 만들기

- 과제 씬: [S04_HW](Assets/S04/S04_HW.unity)
- 정점 6개와 삼각형 8개로 입체 다이아몬드를 구성한다.
- 각 면이 바깥쪽을 향하도록 삼각형 인덱스의 winding order를 지정한다.
- 분홍색 재질과 비스듬한 카메라 구도로 입체 형태를 확인한다.

## 9/10 S04 출석인정과제 - 사각뿔 메시 만들기

- 과제 씬: [S04_Abs_HW](Assets/S04_Abs/S04_Abs_HW.unity)
- 정점 5개로 사각형 밑면과 꼭짓점을 구성한다.
- 밑면 삼각형 2개와 옆면 삼각형 4개의 winding order를 바깥 방향으로 맞춘다.
- Scene 뷰와 Game 뷰에서 완성한 피라미드를 확인한다.

## S05 - 텍스처 캔버스 무늬 만들기

- 과제 씬: [S05_HW](Assets/S05/S05_HW.unity)
- 하나의 씬에 세로 줄무늬와 체스판 무늬 캔버스를 함께 배치한다.
- FillVerticalStripes는 x 좌표를 이용해 색을 번갈아 채운다.
- FillCheckerboard는 x와 y의 칸 번호 합을 이용해 체스판 무늬를 만든다.
- 256×256 텍스처에 16텍셀 간격으로 분홍색과 흰색을 적용한다.

## S06 - 소프트웨어 래스터화와 GL 삼각형 그리기

- 과제 씬: [S06_HW](Assets/S06/S06_HW.unity)
- 꼭짓점 좌표와 색을 수정하고, 무게중심 좌표로 텍셀의 삼각형 내부 여부를 판정해 색칠한다.
- GL.Begin, GL.Color, GL.Vertex3, GL.End로 immediate mode 삼각형을 그린다.
- 하나의 씬에서 왼쪽은 픽셀 판정 결과, 오른쪽은 GL 결과를 확인할 수 있다.

## S07 - 깊이 테스트와 다각형 클리핑

- 과제 씬: [S07_HW](Assets/S07/S07_HW.unity)
- 픽셀마다 보간한 z 값을 깊이 버퍼와 비교하여 겹치는 삼각형의 가려짐을 판정한다.
- 삼각형의 z 값을 기울여 겹치는 위치에 따라 앞에 보이는 색이 바뀌도록 구성한다.
- Sutherland-Hodgman 방식으로 다각형을 왼쪽, 오른쪽, 아래쪽, 위쪽 경계에 차례로 클리핑한다.
- 하나의 씬에 깊이 테스트와 클리핑 결과를 모두 보관하고 필요한 결과만 활성화해 확인한다.

## S08 - 직접 변환의 연산 순서 비교

- 과제 씬: [S08_HW](Assets/S08/S08_HW.unity)
- `S08_DirectTransform.cs`에 이동 후 스케일과 스케일 후 이동 모드를 구현한다.
- 동일한 이동값과 스케일값을 적용하더라도 연산 순서에 따라 오브젝트의 최종 위치가 달라지는 것을 비교한다.
- Game 뷰에서 두 변환 결과를 한 화면에 함께 확인한다.

## S09 - 동차좌표 전단 변환

- 과제 씬: [S09_HW](Assets/S09/S09_HW.unity)
- 4×4 전단 행렬을 직접 작성하여 높이에 비례해 x축 방향으로 다이아몬드를 기울인다.
- 학번 끝자리에 따른 `k=1.8`과 `k=-1.8` 결과를 원본 다이아몬드와 서로 다른 색으로 비교한다.
- 꼭대기 정점의 변환 결과를 Console에서 확인한다.

## S10 - 계층 구조와 행렬 합성

- 과제 씬: [S10_BouncingBallAnimation](Assets/S10/S10_BouncingBallAnimation.unity)
- 공 장치는 부모·자식 계층과 애니메이션으로 공전과 바운스를 구현한다.
- 다이아몬드 장치는 부모 없는 오브젝트와 `S10_DiamondChain_Finish`의 행렬 합성으로 같은 움직임을 구현한다.
- 두 장치에 월드 크기 0.05, 공전 거리 0.15인 달을 추가하고 120프레임마다 한 바퀴 돌도록 구성한다.

## 10/6 S10 출석인정과제 - Chain과 Hierarchy 관람차

- 과제 씬: [S10_Abs_FerrisWheel](Assets/S10_Abs/S10_Abs_FerrisWheel.unity)
- 부모 없는 오브젝트와 `S10_DiamondChain_Finish`의 Chain으로 관람차를 구성한다.
- 같은 관람차를 실제 부모·자식 Hierarchy로 하나 더 구성하여 두 방식의 움직임을 비교한다.
- 바퀴는 240프레임에 한 바퀴 회전하고, 네 캐빈은 반대 방향으로 회전하여 항상 똑바로 서 있도록 구현한다.

## S11 - 뷰 변환과 가상 카메라

- 기본 과제 씬: [S11_VirtualCamera_Finish](Assets/S11/S11_VirtualCamera_Finish.unity)
- 애니메이션 과제 씬: [S11_DiamondView](Assets/S11/S11_DiamondView.unity)
- 가상 카메라의 위치와 회전으로 뷰 행렬을 만들고, 오브젝트를 카메라 기준 좌표로 변환해 Canvas에 그린다.
- `MultiplyMatrixMatrix`에서 행렬 곱을 열 단위로 직접 계산한다.
- 움직이는 다이아몬드와 달을 Canvas에 실시간으로 그려 Game 뷰와 비교한다.
